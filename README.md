# DeskTip · 小憩

轻量的 Windows 桌面休息提醒应用。原生 WPF 界面，桌面宠物「小沐 Mizu」只在提醒时出现，不常驻渲染。

[下载 Windows 版本](https://github.com/KSuperLiu/DeskTip/releases/latest)

![DeskTip 主界面](docs/images/overview.png)

## 运行

- 通用便携版：打开 `release/DeskTip-win-x64/DeskTip.exe`，无需安装 .NET。适用于 Windows 10 / 11 x64。分发时请打包整个文件夹。
- 轻量版：打开 `release/DeskTip-lite/DeskTip.exe`，需要已安装 .NET 8 Desktop Runtime x64。应用本体约 1 MB。
- 关闭窗口或按 Esc 后继续在托盘运行。双击托盘图标重新打开；托盘菜单「退出」才会完全退出。
- 开机启动默认关闭，在「偏好设置」中开启并保存。开机时静默进入托盘。移动应用文件夹后请重新设置开机启动。
- 同一 Windows 会话只运行一个实例，再次打开应用会显示已有实例的设置窗口。

## 默认规则

北京时间，中国工作日；上午 **10:00–11:45**，下午 **13:50–18:30**，每隔 **50 分钟**提醒。

提醒从每个工作时段的开始时间计算，时段结束时间不触发提醒。默认一天的提醒为：

`10:50、11:40、14:40、15:30、16:20、17:10、18:00`

应用在时段中途启动时沿用以上时间网格，不立即补发。更改规则后重新计算下一次未来提醒。如果间隔长于某个工作时段，该时段不触发提醒。

可增删最多 12 个工作时段；设置 1–480 分钟间隔；增删最多 20 条自定义提醒并逐条开启。开启的提醒依次轮换。时间使用 `HH:mm`，时段不能重叠，跨午夜需拆分为两段。

## 提醒与免打扰

- 原创透明背景宠物，静态图片、无持续动画。提醒不自动抢占键盘焦点，45 秒后自动收起。
- 「我去休息啦」结束本次提醒，定时节奏不变；「稍后 5 分钟」延后本次提醒，不改变原时间网格。
- 稍后时间如果会跨出当前工作时段，按钮禁用。稍后提醒与常规提醒碰到一起时只弹出一次。
- 全屏免打扰识别当前前台窗口所在屏幕。触发提醒后最多等待 10 分钟，退出全屏后补发；超时或跨出工作时段即放弃。
- 电脑休眠、会话锁定及恢复时清除过期提醒，避免集中补发。
- 「暂停提醒」是本次运行的临时状态，需要手动继续；永久关闭请在偏好中关闭提醒并保存。
- 「看看提醒效果」仅预览，不改变正式计时或提醒轮换顺序，也不会创建稍后提醒。

## 中国工作日历

内置 **2026 年**放假与调休安排，来源：[国务院办公厅关于 2026 年部分节假日安排的通知（北京市政府转载）](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)。日历数据与提醒逻辑分离，可导入新增年份或公司专属日历。

**未覆盖年份按周一至周五运行，主页显示「日历待更新」**。本应用不会联网更新，不会凭空推算法定调休。新年度官方安排发布后，请导入对应 JSON 数据。

日历文件格式，`true` 为上班，`false` 为休息；未列出的日期按周一至周五判断：

```json
{
  "Years": [2026],
  "Overrides": {
    "2026-10-01": false,
    "2026-10-10": true
  },
  "Source": "日历来源说明"
}
```

上述是格式示例，不是完整年度日历。导入时，同一覆盖年份的旧覆盖记录会被替换，其他年份保留。导入后点击「保存偏好」生效。完整内置日历位于 `src/DeskTip/Assets/calendar-2026.json`。

## 本地数据

设置保存在 `%LOCALAPPDATA%\DeskTip\settings.json`。采用临时文件写入和原子替换，前一版保存在 `settings.json.bak`。异常设置不会在启动时被覆盖；保存默认规则前会备份原文件。

「导出配置」导出已生效的规则、偏好和日历；「导入配置」验证后直接生效。开机启动属于当前电脑的注册表设置，不随配置迁移。使用当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `DeskTip` 项，无需管理员权限。

## 性能设计

无浏览器引擎、无后台网络请求、无持续动画、无后台日志轮询。后台使用 15 秒间隔的 DispatcherTimer；仅提醒到期或等待全屏结束时检查前台窗口。提醒可能比配置时间晚 0–15 秒，系统繁忙时还可能稍有延迟。

宠物按 384 像素宽度解码并共享冻结后的图片，避免反复加载大图。设置窗口关闭后销毁界面，后台仅保留规则、计时和托盘。

包含运行时的便携版文件夹较大，主要是 .NET/WPF 运行时；需要较小的分发体积时可用轻量版，但目标电脑需先安装 .NET 8 Desktop Runtime x64。

实测结果参见 [后台采样记录](docs/performance.json)；此结果只代表当前电脑和测量场景，不是所有电脑的性能保证。首次打开设置和提醒窗口会增加进程工作集。

开发要求：Windows、.NET 8 SDK。没有额外 NuGet 业务依赖。

```powershell
dotnet run --project tests/DeskTip.Tests -c Release
powershell -ExecutionPolicy Bypass -File tools/build.ps1
# 轻量版
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -FrameworkDependent
# 四个界面截图（请先退出已有实例）
.\release\DeskTip-win-x64\DeskTip.exe --capture ".\artifacts\previews"
# 纯后台 45 秒采样（请先退出已有实例）
powershell -ExecutionPolicy Bypass -File tools/measure_idle.ps1
```

测试覆盖默认时间表、午休/下班边界、周末/节假日/调休、重启、不重复提醒、稍后提醒、全屏延迟与过期、睡眠恢复、时钟回拨、暂停、规则校验和 JSON 往返。
