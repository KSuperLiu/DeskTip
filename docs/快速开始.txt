DeskTip · 小憩 1.0

1. 将整个压缩包解压到固定文件夹，双击 DeskTip.exe。
2. 「提醒规则」中可设置时段、间隔和提示文案，点击右下角「保存规则」。
3. 「偏好设置」中可开启开机启动、全屏免打扰并选择工作日历，点击「保存偏好」。
4. 右上角关闭按钮只收起到托盘。双击托盘图标打开设置；托盘菜单「退出」彻底退出。

默认：北京时间，中国工作日，10:00–11:45、13:50–18:30，每隔 50 分钟提醒。
每日时间：10:50、11:40、14:40、15:30、16:20、17:10、18:00。
提醒提供一键完成、稍后 5 分钟，45 秒后自动收起，不抢占输入焦点。
内置 2026 年节假日与调休；新年份需导入更新日历，未覆盖年份按周一至周五运行。
开机启动默认关闭。应用文件夹移动后需要重新保存开机启动设置。

通用便携版：Windows 10/11 x64，无需额外安装 .NET。
轻量版：同样适用于 Windows 10/11 x64，但需要 .NET 8 Desktop Runtime x64。
请保留应用文件夹中的所有文件，不要只拷贝 DeskTip.exe。
设置保存在当前用户的 %LOCALAPPDATA%\DeskTip 目录。

本地离线运行，不收集上传数据，无持续动画，无声音提醒。
